# Painel de Anúncios de Venda de Carros

Aplicativo web desenvolvido com Streamlit para explorar um conjunto de dados de anúncios de venda de carros nos EUA.

## Funcionalidades

- **Histograma:** ao clicar no botão "Criar histograma", o app mostra a distribuição da quilometragem (odometer) dos veículos.
- **Gráfico de dispersão:** ao clicar no botão "Criar gráfico de dispersão", o app mostra a relação entre quilometragem e preço.

## Tecnologias

- Python
- Streamlit
- Pandas
- Plotly Express

## Como executar localmente

1. Instale as dependências: `pip install -r requirements.txt`
2. Rode o app: `streamlit run app.py`
